  Refactor `ml/eval/models/graphsage_wrapper.py` with the following changes:

  1. **Replace self-supervised MSE loss with InfoNCE contrastive loss (per D-03):**
     - Positive pairs: nodes connected by similarity edges (from KNN edge_index)
     - Negative pairs: randomly sampled non-neighbor nodes (uniform sampling, num_negatives = num_edges * 2)
     - InfoNCE loss: `-log(exp(sim_pos/tau) / sum(exp(sim_neg/tau)))` where sim_pos is cosine similarity between positive pair embeddings, sim_neg between negative pair embeddings
     - Temperature `tau` configurable via constructor parameter (default: 0.5)
     - Keep the existing self-supervised MSE loss as a fallback: add `loss_type` parameter ('contrastive' or 'reconstruction') to `__init__` and `train()`

  2. **Implement proper warm-train + full-inference pattern (per D-04):**
     - `train()` accepts `warm_edge_index` (edges only between warm nodes) and trains only on that subgraph
     - `predict()` runs the full graph (warm + cold nodes + all edges) through the trained model to generate embeddings for ALL nodes via inductive message passing
     - Cold nodes with at least one neighbor in the graph receive embeddings propagated from their warm neighbors
     - After `predict()` generates full-graph embeddings, compute cosine similarity matrix on normalized embeddings, then select top-k recommendations per node (excluding self)

  3. **Implement degree-0 fallback (per D-04):**
     - Before `predict()` runs the full graph, compute node degrees from the full edge_index
     - For nodes with degree == 0 (no neighbors), skip message passing — use direct cosine similarity on the raw 432-dim feature vector instead
     - The fallback predictions replace the cold-start recommendations for degree-0 nodes

  4. **Refactor `predict_cold_start()` to perform proper inductive masking:**
     - Accept `warm_node_ids`, `cold_node_ids`, `full_edge_index`, and `node_features`
     - Train on warm subgraph only (edges connecting warm nodes)
     - Build full inference graph: warm + cold nodes, edges between warm nodes AND edges from warm to cold (no cold-to-cold edges — those aren't known at training time)
     - Return recommendations only for cold_start nodes (via cold_node_ids filtering)
     - For degree-0 cold nodes, return feature-only similarity fallback

  5. **Update `GraphSAGE.forward()` to handle the mean aggregation more efficiently:**
     - Keep the existing mean aggregation + linear transform + ReLU+dropout pattern
     - Add proper handling for empty edge_index (return zero-centered embeddings with warning log)
     - Add docstring that this is custom mean-aggregation (not torch-geometric based)

  6. **Input dimension:** The concatenated feature vector is 432-dim (48 accord one-hot + 384 embedding, per D-02). Set `input_dim` default to 432.

  7. **Add logging throughout:** Log training epoch losses, number of warm/cold/degree-0 nodes, and inference graph dimensions.

     ```python
     def _build_features(self, df: pd.DataFrame) -> tuple[np.ndarray, list[str]]:
         """Build 432-dim feature matrix per D-02.
         
         Returns:
             node_features: ndarray of shape (num_nodes, 432)
             node_ids: list of fragrance_id strings aligned with rows
         """
         import numpy as np
         import json
         
         # Load precomputed embeddings
         embeddings_path = "ml/data/embeddings.npy"
         index_path = "ml/data/embedding_index.json"
         embeddings = np.load(embeddings_path)
         with open(index_path, "r") as f:
             embedding_index = json.load(f)
         
         # Get all unique accords across the dataset for consistent one-hot encoding
         all_accords = sorted(df["primary_accord"].unique())
         accord_to_idx = {a: i for i, a in enumerate(all_accords)}
         
         node_features_list = []
         node_ids = []
         
         for _, row in df.iterrows():
             fragrance_id = row["fragrance_id"]
             if fragrance_id not in embedding_index:
                 logger.warning(f"Fragrance {fragrance_id} not in embedding index — skipping")
                 continue
             
             # 48-dim accord one-hot
             accord = row.get("primary_accord", "Unknown")
             accord_vec = np.zeros(len(all_accords), dtype=np.float32)
             if accord in accord_to_idx:
                 accord_vec[accord_to_idx[accord]] = 1.0
             
             # 384-dim description embedding
             emb_idx = embedding_index[fragrance_id]
             emb_vec = embeddings[emb_idx].astype(np.float32)
             
             # Concatenate: 48 + 384 = 432
             feature_vec = np.concatenate([accord_vec, emb_vec])
             node_features_list.append(feature_vec)
             node_ids.append(fragrance_id)
         
         return np.array(node_features_list, dtype=np.float32), node_ids
     ```
